# My Library

Учебный React-проект — электронная библиотека с фильтрацией книг по жанрам.

## Функционал

- отображение полного каталога книг;
- отображение общей статистики библиотеки;
- фильтрация книг по жанрам с помощью `filter()`;
- отображение книг через `map()`;
- передача данных через `props`;
- использование `key`;
- отображение статуса доступности книги;
- отображение отметки `Классическое издание` для книг до 2000 года;
- сообщение при отсутствии книг в категории;
- универсальный компонент `Card` с использованием `children`;
- вывод жанров через массив `genres` и `map()`.

## Компоненты

- `Header`
- `LibraryStats`
- `BookList`
- `BookCard`
- `AvailabilityBadge`
- `Card`
- `Footer`

## Данные книги

Каждая книга содержит:

- `id`
- `title`
- `author`
- `year`
- `genre`
- `copies`

## Жанры

- Художественная литература
- Учебная литература
- Детская литература
- Публицистика
- Научно-популярная литература
